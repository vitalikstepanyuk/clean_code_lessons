PR відділ компанії потребує систему, що дозволить публікувати пости в різних соціальних мережах через єдиний інтерфейс/API.  
Потрібно враховувати такі вимоги, як необхідність застосування налаштовуємих фільтрів конфіденційності, блокуючих публікацію за небажаними словами, фільтрів-трансформерів для перевірки та виправлення орфографічних помилок, додавання корпоративного колонтитула та можливо інших.  

Спроектуйте та зробить PoC цієї системи публікації за допомогою патернів проектування.
